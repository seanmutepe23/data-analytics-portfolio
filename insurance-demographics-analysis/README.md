# Insurance Demographics & Cost Analysis

## Overview

This project analyses insurance charges across different demographic and behavioural categories using Google Looker Studio.

## Objectives

The analysis examines insurance charges according to:

- Age
- Sex
- BMI
- Smoking status
- Region
- Children status

## Key Analysis

The dashboard explores:

- Revenue by age and BMI
- Revenue from smokers versus non-smokers
- Average charges by BMI category
- Average charges by age category
- Record count by sex
- Total premiums by age category and children status
- Revenue distribution across regions
- Total premiums by BMI category
- Total premiums by sex and smoker category

## Tool Used

Google Looker Studio

The completed analysis is available in the PDF included in this repository.
